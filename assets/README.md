# Assets

Drop your real files in here to replace the site's placeholders:

- `resume.pdf` — your resume PDF. The "Download Resume" button in `index.html` already links to `assets/resume.pdf`, so it'll work automatically once this file exists.
- `profile.jpg` (or `.png`) — your headshot. In `index.html`, find the `hero-photo` div and swap the `photo-placeholder` div for `<img src="assets/profile.jpg" alt="Mariah Landes" />`.
- Project screenshots/GIFs — name them however you like (e.g. `project1.png`, `project1.gif`). In each `.project-media` div in `index.html`, swap the `media-placeholder` div for `<img src="assets/your-file.png" alt="Project name">`.
